# 发明专利：一种基于图像识别的细胞自动计数系统

---

## 一、现有技术

### 1.1 技术发展现状

细胞计数是生物医学研究、临床诊断和药物筛选中的基础性工作。目前细胞计数技术主要经历以下几个发展阶段：

**（1）人工计数阶段**
- 使用血球计数板在显微镜下人工目视计数
- 依赖操作者经验，效率低且主观性强

**（2）基于传统图像处理的自动计数阶段**
- 采用阈值分割（如Otsu法、自适应阈值）将细胞与背景分离
- 结合形态学操作（开运算、闭运算、距离变换）处理粘连细胞
- 使用分水岭算法（Watershed）分割重叠细胞
- 通过连通域分析统计细胞数量

**（3）基于传统深度学习的检测计数阶段**
- 采用目标检测模型（如YOLO系列、Faster R-CNN）进行细胞定位与计数
- 需要大量人工标注的训练数据
- 模型泛化能力受限于训练数据集

### 1.2 现有技术存在的缺陷

**缺陷一：对粘连/重叠细胞分割效果差**
- 传统阈值分割方法在细胞密集区域容易将多个粘连细胞误判为单一目标
- 分水岭算法对参数敏感，易产生过分割或欠分割

**缺陷二：对细胞形态变化适应性弱**
- 当细胞因拥挤发生形变（挤压成椭圆形、半圆形）时，基于圆形假设的传统方法漏检率高
- 固定形态学模板无法覆盖细胞的多样性形态

**缺陷三：需要大量标注数据**
- 传统深度学习检测方法依赖大量人工标注的训练样本
- 不同细胞类型、不同成像条件下需要重新标注和训练
- 标注成本高、周期长

**缺陷四：无法灵活指定感兴趣区域(ROI)**
- 现有方法通常对整幅图像进行处理
- 无法针对特定区域进行局部精确计数
- 在部分视野存在杂质或干扰时缺乏灵活性

**缺陷五：缺乏人机协同修正机制**
- 全自动方法一旦产生误检或漏检，用户无法直接修正
- 缺乏直观的手动添加/删除标记功能

## 二、技术方案

### 2.1 系统整体架构

本系统采用三层架构设计，自下而上分别为：

**（1）模型层**
- 核心组件：LocateAnything-3B视觉语言模型（Vision-Language Model）
- 模型特点：3B参数规模，支持图像-文本联合推理，输出标准化边界框坐标
- 输出格式：`<box><x1><y1><x2><y2></box>`，坐标归一化为千分比

**（2）后端服务层**
- 框架：FastAPI异步Web服务框架
- 核心模块：
  - 细胞检测模块：调用视觉语言模型进行细胞定位
  - NMS去重模块：基于IoU阈值的非极大值抑制
  - ROI裁剪模块：支持用户框选感兴趣区域
  - 人机协同模块：支持手动添加/删除标记点

**（3）前端交互层**
- 基于HTML/JavaScript的Web可视化界面
- 支持标点模式和框选模式两种交互方式
- 提供图像缩放、平移、撤销、重置等画布操作

### 2.2 细胞计数方法流程

本方法包含以下核心步骤：

#### 步骤S1：图像输入
- 接收用户上传的显微镜图像（支持JPG/PNG/BMP/TIFF/WebP格式）
- 将图像统一转换为RGB格式
- 记录图像原始尺寸（width, height）用于坐标换算

#### 步骤S2：ROI区域裁剪（可选）
- 用户可选择整图计数或框选区域计数
- 框选模式下，获取用户绘制的矩形框坐标(x1, y1, x2, y2)
- 验证框选区域有效性（宽高均大于10像素）
- 对有效区域执行图像裁剪，仅保留感兴趣区域

#### 步骤S3：基于视觉语言模型的细胞定位
- 构建专用语义提示词（Prompt），内容为：
  ```
  "Locate all the instances that match the following description: cell. 
   These appear as small circular, oval, or semi-circular shapes. 
   When cells are crowded or touching, they may be deformed, squeezed into 
   ellipses or half-circles. Even if cells are touching or overlapping, 
   each cell must be enclosed in a SEPARATE bounding box. 
   Do NOT group multiple cells into one large box. 
   Each bounding box should tightly enclose a single cell."
  ```
- 将图像和提示词输入LocateAnything-3B模型
- 模型输出包含所有检测到细胞的边界框坐标文本

#### 步骤S4：边界框解析
- 使用正则表达式解析模型输出文本，提取`<box><x1><y1><x2><y2></box>`格式坐标
- 将归一化千分比坐标转换为像素坐标：
  - `px = x / 1000 * image_width`
  - `py = y / 1000 * image_height`
- 确保坐标规范：x1≤x2，y1≤y2

#### 步骤S5：NMS非极大值抑制去重
- 计算每个边界框的面积：`area = (x2-x1) × (y2-y1)`
- 按面积从大到小排序
- 依次选取最大框，计算与其余框的IoU（交并比）：
  - `IoU = 交集面积 / 并集面积`
- 当IoU ≥ 阈值（默认0.3）时，剔除重叠框
- 输出精简后的边界框列表

#### 步骤S6：中心点计算与可视化
- 对每个边界框计算中心点坐标：
  - `center_x = (x1 + x2) / 2`
  - `center_y = (y1 + y2) / 2`
- 在图像上绘制红色标记点（自动检测）或绿色标记点（手动添加）
- 在左上角叠加显示计数文字

#### 步骤S7：人机协同修正
- 用户可在可视化界面上手动添加遗漏的细胞标记点
- 用户可点击已有标记点删除误检
- 系统实时更新计数结果和可视化图像

### 2.4 工作原理

本系统的工作原理是：利用大规模视觉语言模型（VLM）的零样本检测能力，通过语义提示词引导模型理解细胞的形态特征，直接输出细胞边界框坐标。系统对输出结果进行解析和去重后，在可视化界面上展示给用户。用户可通过人机交互方式对检测结果进行修正，最终得到准确的细胞计数结果。

核心创新在于：
1. **零样本检测**：无需标注训练数据，利用预训练VLM的泛化能力直接检测细胞
2. **语义引导**：通过精心设计的提示词，让模型理解细胞在拥挤/形变条件下的形态特征
3. **ROI灵活选择**：支持整图或局部区域计数，适应不同应用场景
4. **人机协同**：自动检测与手动修正相结合，确保结果准确性

## 三、改进之处（创新点）+ 有益效果

### 3.1 创新点一：基于视觉语言模型的零样本细胞检测

**改进内容：**
- 摒弃传统深度学习方法对大量标注数据的依赖
- 采用LocateAnything-3B视觉语言模型，利用其预训练阶段学到的通用视觉知识
- 通过语义提示词直接引导模型定位细胞，实现零样本（Zero-shot）检测

**有益效果：**
- 无需任何标注训练数据，节省大量人工标注成本
- 模型具备跨场景泛化能力，适用于不同类型的细胞（细菌、酵母、哺乳动物细胞等）
- 部署即用，无需针对新场景重新训练

### 3.2 创新点二：语义提示词引导的形态感知定位

**改进内容：**
- 设计专用提示词，明确描述细胞的多种形态特征：
  - 正常形态：圆形、椭圆形
  - 拥挤形变：半圆形、挤压变形
- 在提示词中强调"每个细胞必须用独立边界框标注"，防止多细胞被归为一个大框
- 提示词中明确要求"紧密包围单个细胞"，提高定位精度

**有益效果：**
- 模型能够识别正常形态和形变状态的细胞，降低漏检率
- 对粘连/重叠细胞的分离检测能力显著提升
- 边界框紧贴细胞边缘，定位精度更高

### 3.3 创新点三：灵活的ROI框选区域计数

**改进内容：**
- 前端支持用户通过鼠标拖拽绘制矩形框选区域
- 后端接收框选坐标后，对图像进行裁剪，仅对ROI区域进行推理计数
- ROI区域有效验证：宽度和高度均需大于10像素，避免无效操作

**有益效果：**
- 用户可排除杂质、气泡、划痕等干扰区域，提高计数准确性
- 支持对特定感兴趣区域进行精确计数
- 在大视野图像中可局部放大分析，操作更灵活

### 3.4 创新点四：NMS非极大值抑制去重

**改进内容：**
- 对模型输出的原始边界框列表进行去重处理
- 基于IoU（交并比）阈值判断框之间的重叠程度
- 按面积从大到小排序，优先保留大框，逐步剔除重叠小框
- IoU阈值可配置（默认0.3），平衡去重力度与保留率

**有益效果：**
- 有效去除重复检测框，避免同一细胞被多次计数
- 保证每个细胞仅对应一个最优边界框
- 参数可调，适应不同场景需求

### 3.5 创新点五：人机协同修正机制

**改进内容：**
- 自动检测完成后，在可视化界面上以红色标记点展示检测结果
- 用户可在画布空白处点击添加遗漏的细胞标记（显示为绿色）
- 用户可点击已有标记点删除误检目标
- 标记点实时更新，计数数字同步刷新
- 支持多步撤销和一键重置

**有益效果：**
- 自动检测与人工审核相结合，确保最终结果准确可靠
- 对模型漏检的目标可快速手动补充
- 对模型误检的目标可快速剔除
- 提供操作灵活性，用户体验好

## 五、具体实施方式的补充说明

### 5.1 模型部署

LocateAnything-3B模型部署在具有CUDA支持的GPU服务器上，推荐显存≥8GB。模型加载时采用bfloat16精度以降低显存占用。后端服务通过LocateAnythingWorker类封装模型推理接口，支持共享单例模式，避免重复加载。

### 5.2 API接口设计

系统提供以下RESTful API接口：

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/cell/count` | POST | 细胞自动计数（支持ROI框选） |
| `/api/cell/add_point` | POST | 手动添加细胞标记点 |
| `/api/cell/remove_point` | POST | 删除细胞标记点 |
| `/api/health` | GET | 健康检查 |

### 5.3 参数配置

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| nms_iou_threshold | 0.3 | NMS交并比阈值 |
| point_radius | 5 | 标记点半径（像素） |
| temperature | 0.7 | 模型推理温度参数 |
| generation_mode | hybrid | 推理模式（mtp/ntp/hybrid） |

### 5.4 输出结果

系统输出包含以下内容：
- **count**：最终细胞计数结果
- **raw_count**：NMS去重前的原始检测数
- **points**：所有标记点的坐标列表（含自动/手动来源标识）
- **image_base64**：可视化结果图像的Base64编码
- **crop_info**：ROI裁剪区域信息（如适用）
