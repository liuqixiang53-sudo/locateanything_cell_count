# 发明专利申请书

## 发明名称：一种基于视觉语言模型的细胞自动计数系统及方法

## 一、现有技术

### 1.1 细胞计数的应用背景

细胞计数是生物医学研究、临床诊断、药物筛选、细胞培养质量控制等领域中最基础且最频繁执行的实验操作之一。准确的细胞数量信息对于以下应用场景至关重要：

- **细胞培养**：确定细胞密度以进行传代、冻存或接种实验
- **药物筛选**：评估药物对细胞增殖或凋亡的影响
- **毒理学研究**：检测化学物质对细胞活力的影响
- **临床诊断**：血液细胞计数用于诊断贫血、感染等疾病
- **微生物检测**：细菌或酵母细胞计数用于食品安全和发酵工业控制

### 1.2 现有技术的发展情况及存在的缺点

#### 1.2.1 人工计数技术

传统的细胞计数方法主要依赖人工操作，使用血球计数板（Hemocytometer）在显微镜下由实验人员目视计数。

**存在的缺点：**
- **主观性强**：不同操作者对模糊边界细胞的判定标准不一致，导致计数结果存在较大的人为偏差
- **效率低下**：单次计数通常需要3-5分钟，大量样本处理时耗时巨大
- **易疲劳出错**：长时间计数易导致视觉疲劳，漏检和重复计数概率增加
- **不可追溯**：计数结果缺乏图像记录和坐标信息，无法复核

#### 1.2.2 基于传统图像处理的自动计数技术

随着数字图像处理技术的发展，出现了基于传统图像处理算法的自动细胞计数方法。该类方法的一般流程为：首先对显微镜图像进行预处理（灰度化、滤波去噪、对比度增强），然后采用阈值分割方法（如全局Otsu阈值、自适应阈值）将细胞区域与背景分离，接着通过形态学操作（开运算、闭运算、距离变换）进行后处理，最后使用连通域分析或分水岭算法分割粘连细胞并统计数量。

**存在的缺点：**
- **对粘连/重叠细胞分割效果差**：传统阈值分割方法假设细胞之间有明显的亮度差异和空间间隔。当细胞因高密度培养而相互接触甚至部分重叠时，简单的阈值分割会将多个粘连细胞合并为一个连通域，导致严重低估细胞数量。分水岭算法虽可分割粘连目标，但对距离变换的阈值参数极为敏感，阈值过高导致过分割，阈值过低导致欠分割。
- **对细胞形态变化的适应性弱**：传统方法通常基于圆形或近似圆形的形态假设来设计检测模板和分割策略。当细胞因拥挤而发生形变（如被挤压成椭圆形、半圆形甚至不规则形状）时，基于圆形假设的模板匹配和霍夫变换等方法会产生大量漏检。
- **对成像条件变化敏感**：传统图像处理方法的性能高度依赖于图像质量。当显微镜的光照条件不均匀、存在污渍或气泡、图像对比度不足、焦距偏差导致细胞边缘模糊时，阈值分割和边缘检测的效果会显著下降。

#### 1.2.3 基于传统深度学习的检测计数技术

近年来，基于深度学习的目标检测方法被广泛应用于细胞计数任务，典型模型包括YOLO系列、Faster R-CNN、SSD等。这些方法通过在大量标注数据上训练，学习细胞的视觉特征并输出检测框。

**存在的缺点：**
- **需要大量标注数据**：传统深度学习检测模型需要在数千至数万张标注图像上进行训练，每张图像中的每个细胞都需要人工标注边界框坐标。对于显微镜细胞图像，单张图像可能包含数百个细胞，标注成本极高。
- **泛化能力受限**：训练好的模型仅对与训练数据分布相似的图像有效。当细胞类型、染色方法、显微镜型号、放大倍率、光照条件发生变化时，模型性能会显著下降，需要重新收集数据、重新标注、重新训练。
- **无法灵活指定感兴趣区域（ROI）**：现有基于深度学习的检测方法通常对整幅图像进行推理，无法方便地指定感兴趣区域进行局部计数，用户无法排除图像中的杂质、气泡、划痕等干扰区域。
- **缺乏人机协同修正机制**：全自动深度学习方法一旦产生误检或漏检，用户无法在结果界面上直接进行修正，需要重新调整模型参数或重新训练模型。

### 1.3 现有技术总结

综上所述，现有细胞计数技术存在以下共性问题：
1. 人工计数效率低、主观性强、易出错
2. 传统图像处理方法对粘连细胞、形变细胞、低质量图像的适应性差
3. 传统深度学习检测模型依赖大量标注数据、泛化能力弱、缺乏灵活性
4. 缺乏有效的人机协同修正机制

本发明正是针对上述技术缺陷，提出了一种全新的基于视觉语言模型的细胞自动计数系统及方法。

## 二、技术方案

### 2.1 系统组成及连接关系

本发明提供一种基于视觉语言模型的细胞自动计数系统，其特征在于，由以下三个层级组成：

**（1）模型层（301）**

模型层的核心组件为LocateAnything-3B视觉语言模型（302），该模型具有30亿参数规模，支持图像-文本联合推理，能够根据输入的图像和自然语言提示词，输出图像中符合提示词描述的目标位置信息。模型输出格式为标准化边界框坐标文本：`<box><x1><y1><x2><y2></box>`，其中x1、y1为边界框左上角坐标，x2、y2为边界框右下角坐标，坐标值归一化为相对于图像尺寸的千分比（即0-1000范围内的整数）。模型层的输入为待检测图像（303）和语义提示词（304），输出为边界框坐标文本（305）。模型部署在具有CUDA支持的GPU服务器上，采用bfloat16精度以降低显存占用，通过LocateAnythingWorker类封装推理接口并支持共享单例模式。

**（2）后端服务层（201）**

后端服务层采用FastAPI异步Web服务框架，提供RESTful API接口，包含以下功能模块：
- **图像解码模块（202）**：接收前端上传的图像文件，解码为RGB格式的Image对象，支持JPG、PNG、BMP、TIFF、WebP等格式
- **ROI裁剪模块（203）**：接收前端传递的矩形框选坐标，对有效区域执行裁剪操作，仅保留感兴趣区域用于后续推理
- **模型推理模块（204）**：通过LocateAnythingWorker共享实例调用视觉语言模型，将图像和语义提示词传入模型获取边界框坐标文本，支持配置generation_mode和temperature参数
- **NMS去重模块（205）**：对模型输出的原始边界框列表进行非极大值抑制去重处理，按面积排序后依次选取最大框，计算与剩余框的IoU并剔除重叠框
- **边界框解析模块**：使用正则表达式从模型输出文本中提取坐标值，将归一化千分比坐标转换为像素坐标
- **中心点计算模块**：对每个去重后的边界框计算中心点坐标，用于可视化标记和最终计数
- **可视化生成模块（208）**：在原始图像上绘制检测结果的可视化标记点，自动检测点为红色，手动添加点为绿色，叠加计数文字
- **手动添加模块（206）**：接收前端传递的点击坐标，在指定位置添加手动标记点并重新生成可视化图像
- **手动删除模块（207）**：接收前端传递的待删除点索引，从列表中移除对应点并重新生成可视化图像

**（3）前端交互层（101）**

前端交互层基于HTML/CSS/JavaScript实现，提供完整的Web可视化界面，包含以下功能组件：
- **图像上传组件（102）**：支持点击选择和拖拽上传两种方式，读取本地图像文件并加载到Canvas画布上
- **画布操作组件（103）**：使用HTML5 Canvas元素渲染图像和标记点，支持缩放、平移、框选区域绘制、点击添加/删除标记点等交互操作
- **参数调节组件（104）**：提供滑块和下拉框调节NMS IoU阈值、推理模式等参数，修改实时显示当前值并在下次计数时生效
- **结果导出组件（105）**：将当前标记点列表导出为CSV文件，包含序号、坐标、类型等信息

**各层之间的连接关系：**
前端交互层（101）通过HTTP/REST API请求通道（106）与后端服务层（201）通信。后端服务层（201）通过模型输入输出通道（209）调用模型层（302），将图像和提示词输入模型，获取边界框坐标文本输出。

### 2.2 细胞计数方法流程

本发明提供的细胞计数方法包含以下步骤：

**步骤S1：图像输入**

接收用户上传的显微镜图像文件，支持的格式包括JPG、PNG、BMP、TIFF、WebP。将图像统一转换为RGB色彩模式，记录图像原始尺寸（width, height），单位为像素。

**步骤S2：ROI区域裁剪（可选）**

判断用户是否提供了ROI框选区域坐标（x1, y1, x2, y2）。验证框选区域的有效性：宽度（x2-x1）和高度（y2-y1）均大于10像素。若满足条件，则执行图像裁剪操作，仅保留用户选定的感兴趣区域；否则使用整幅图像进行后续处理。

**步骤S3：基于视觉语言模型的细胞定位**

构建专用语义提示词（CELL_PROMPT），具体内容如下：

```
"Locate all the instances that match the following description: cell. 
These appear as small circular, oval, or semi-circular shapes. 
When cells are crowded or touching, they may be deformed, squeezed into 
ellipses or half-circles. Even if cells are touching or overlapping, 
each cell must be enclosed in a SEPARATE bounding box. 
Do NOT group multiple cells into one large box. 
Each bounding box should tightly enclose a single cell."
```

将该提示词和待检测图像输入LocateAnything-3B模型的predict()方法。模型内部执行图像编码、文本编码、多模态融合、自回归生成，输出包含边界框坐标的文本。模型输出格式为：`<box><x1><y1><x2><y2></box>`，坐标值为归一化千分比（0-1000范围内的整数）。

推理参数包括：
- generation_mode：推理生成模式，可选"hybrid"（混合模式）、"fast"（快速模式）、"slow"（精细模式），默认"hybrid"
- temperature：采样温度参数，控制输出的随机性和多样性，范围0.0-1.0，默认0.1

**步骤S4：边界框解析**

使用正则表达式 `r"<box><(\d+)><(\d+)><(\d+)><(\d+)></box>"` 从模型输出文本中提取所有匹配的坐标值。将归一化千分比坐标转换为像素坐标：
```
px = x / 1000 × image_width
py = y / 1000 × image_height
```
确保坐标规范性：x1=min(px1,px2)，y1=min(py1,py2)，x2=max(px1,px2)，y2=max(py1,py2)。记录原始检测数量（raw_count）。

**步骤S5：NMS非极大值抑制去重**

对模型输出的原始边界框列表进行NMS去重处理，具体步骤为：

S5-1：面积计算——计算每个边界框的面积：area=(x2-x1)×(y2-y1)
S5-2：面积排序——按面积从大到小排序
S5-3：迭代筛选——依次选取面积最大的框加入保留列表，计算该框与剩余所有框的IoU（交并比），当IoU≥阈值（默认0.3）时剔除该重叠框
S5-4：输出去重结果——返回保留列表作为去重后的边界框结果

IoU计算公式：
```
交集面积 inter_area = max(0, x2_inter-x1_inter) × max(0, y2_inter-y1_inter)
并集面积 union_area = area1 + area2 - inter_area
IoU = inter_area / union_area
```

**步骤S6：中心点计算与可视化**

对每个去重后的边界框计算中心点坐标：center_x=(x1+x2)/2，center_y=(y1+y2)/2。在原始图像上绘制标记点，自动检测的点使用红色（RGB:255,0,0）填充，手动添加的点使用绿色（RGB:0,255,0）填充，均带白色描边（宽度2像素）。在图像左上角叠加显示计数文字（如"Count: 156"）。将可视化图像编码为JPEG格式的Base64字符串。

**步骤S7：人机协同修正**

将可视化图像和点列表返回给前端界面，用户可进行以下修正操作：

（a）手动添加遗漏点：在标点模式下，用户点击画布空白区域，在指定坐标处添加一个新的手动标记点（source标识为"manual"）

（b）手动删除误检点：用户点击已有标记点（距离阈值15像素），从点列表中移除该点

（c）操作历史管理：前端维护history数组作为操作历史栈，每次手动操作前将当前点列表的深拷贝推入历史栈，点击"撤销"按钮时弹出并恢复

（d）重置操作：清空所有标记点、历史栈、框选区域，恢复图像到初始状态

**步骤S8：结果输出与导出**

输出最终细胞计数结果（count）、原始检测数量（raw_count）、所有标记点的完整坐标列表（points）、可视化结果图像（image_base64）、ROI裁剪区域信息（crop_info）。用户可将标记点列表导出为CSV文件，包含序号、X坐标、Y坐标、类型（自动/手动）列，以及总计行。

### 2.3 API接口设计

系统提供以下RESTful API接口：

**（1）细胞自动计数接口** `POST /api/cell/count`
- 请求参数：file（图像文件）、x1/y1/x2/y2（可选ROI坐标）、nms_iou_threshold（默认0.3）、point_radius（默认5）、temperature（默认0.1）、generation_mode（默认"hybrid"）
- 响应：success、count、raw_count、crop_info、points、image_base64

**（2）手动添加标记点接口** `POST /api/cell/add_point`
- 请求参数：file、x、y、points_json
- 响应：同上

**（3）删除标记点接口** `POST /api/cell/remove_point`
- 请求参数：file、index、points_json
- 响应：同上

**（4）健康检查接口** `GET /api/health`
- 响应：{"status": "ok", "model_loaded": boolean}

### 2.4 工作原理

本发明的工作原理可概括为：利用大规模视觉语言模型（VLM）的零样本检测能力，通过精心设计的语义提示词引导模型理解细胞的形态特征（包括正常形态和拥挤形变状态），直接输出细胞边界框的归一化坐标文本。后端服务对模型输出进行解析和非极大值抑制去重后，在原始图像上绘制可视化标记点并返回给前端界面。用户可通过人机交互方式（标点模式下的点击添加/删除，框选模式下的区域选择）对检测结果进行实时修正，最终得到准确的细胞计数结果。

核心工作机制包括四个层面：

**（1）零样本检测机制**：不依赖任何针对细胞计数的标注训练数据。LocateAnything-3B模型在预训练阶段已从海量图像-文本对中学习到了丰富的视觉概念，通过在推理阶段使用语义提示词，激活模型对细胞视觉特征的记忆和识别能力，实现零样本检测。

**（2）语义引导机制**：提示词不仅指明目标类别（"cell"），还详细描述了细胞在不同场景下的形态变化：正常状态下为"圆形、椭圆形"，拥挤状态下为"半圆形、挤压变形"。同时明确强调独立标注要求和精确定位要求，防止模型将多个粘连细胞归并为一个大框。

**（3）ROI灵活选择机制**：用户可在前端界面通过框选模式绘制矩形选框，系统仅对选框内的区域进行推理计数。框选区域的有效验证（宽高均大于10像素）确保推理操作的合理性。

**（4）人机协同机制**：自动检测与手动修正相结合，确保最终结果准确可靠。自动检测覆盖大部分可见细胞，手动修正处理模型未能检测到的遗漏目标和误检目标。操作历史管理支持多步撤销，提供容错能力。

## 三、改进之处（创新点）+有益效果（优点）

### 3.1 创新点一：基于视觉语言模型的零样本检测

**改进之处：**
本发明摒弃了传统深度学习方法对大量标注训练数据的依赖，首次将大规模视觉语言模型（LocateAnything-3B）应用于细胞计数任务。通过在推理阶段使用精心设计的语义提示词（CELL_PROMPT），激活模型对细胞视觉特征的识别能力，实现零样本检测。提示词不仅指明目标类别，还详细描述了细胞在不同场景下的形态变化，并明确要求独立标注和精确定位。

**有益效果：**
- **零标注成本**：无需任何针对细胞计数的标注训练数据，部署时仅需准备模型文件即可直接使用，显著降低应用门槛和部署成本。相比传统深度学习方法需要数千至数万张标注图像，本发明可节省100%的标注人力成本。
- **形态感知能力强**：通过语义提示词引导，模型能够理解细胞在不同场景下的形态变化。对于正常形态的细胞（圆形、椭圆形），模型可以准确定位；对于拥挤状态下发生形变的细胞（挤压成椭圆形、半圆形），模型同样能够有效识别。
- **泛化能力强**：模型在预训练阶段已从海量图像-文本对中学习到了丰富的视觉概念，对不同类型的细胞、不同的显微镜型号、不同的放大倍率均具有良好的适应性，无需针对每种场景重新训练。

### 3.2 创新点二：ROI灵活框选计数

**改进之处：**
本发明在前端界面实现了框选模式，用户可通过鼠标拖拽绘制矩形选框，后端仅对选框内的区域进行推理计数。框选区域的有效验证（宽高均大于10像素）确保推理操作的合理性。在前端，框选区域以虚线矩形框实时显示，松开鼠标后自动验证有效性。

**有益效果：**
- **排除干扰区域**：用户能够排除图像中的杂质、气泡、划痕等干扰区域，提高计数准确性。
- **局部精确计数**：用户可对特定子区域进行精确计数，在大视野图像中局部放大分析特定区域。
- **操作灵活方便**：框选操作通过鼠标拖拽即可完成，直观简便，无需输入复杂坐标参数。

### 3.3 创新点三：人机协同修正机制

**改进之处：**
本发明提供自动检测与手动修正相结合的人机协同机制。用户可在前端Canvas画布上进行以下操作：
- 在标点模式下，点击空白区域手动添加遗漏的细胞标记点（绿色显示）
- 点击已有标记点手动删除误检目标
- 操作历史管理支持多步撤销
- 自动检测点（红色）与手动添加点（绿色）在视觉上明确区分

**有益效果：**
- **结果准确可靠**：自动检测覆盖大部分可见细胞，手动修正处理模型未能检测到的遗漏目标和误检目标，确保最终计数结果准确。
- **直观易用**：红色/绿色标记点区分自动/手动来源，用户可清晰了解哪些是模型检测到的、哪些是自己手动添加的。
- **容错能力强**：操作历史管理支持多步撤销，提供容错能力，用户可放心进行手动修正。
- **数据完整可追溯**：系统输出包含完整的标记点坐标列表（含自动/手动来源标识），每个标记点的X、Y坐标均精确到图像原始像素级别，可导出为CSV文件用于后续分析。

### 3.4 创新点四：基于原生Web技术的轻量级前端

**改进之处：**
本发明前端交互层采用纯HTML5+CSS3+JavaScript原生实现，不依赖任何第三方前端框架（如React、Vue、jQuery等）。核心功能通过HTML5 Canvas 2D API、Fetch API、FileReader API、Blob API等浏览器原生接口实现。

**有益效果：**
- **轻量级部署**：前端为单HTML文件，无需构建工具、无需编译、无需安装依赖，直接通过浏览器即可访问。
- **跨平台兼容**：基于Web标准实现，支持所有现代浏览器（Chrome、Firefox、Safari、Edge等），可在Windows、macOS、Linux等操作系统上使用。
- **远程访问方便**：服务支持SSH端口转发、局域网直接访问等多种远程连接方式，适合实验室多人协作使用，用户无需安装任何客户端软件。

### 3.5 创新点五：可配置参数适配多场景

**改进之处：**
本发明提供NMS IoU阈值、温度参数、推理模式等可调参数，用户可根据实际图像质量和检测需求灵活调整。参数修改通过前端滑块和下拉框完成，实时生效，无需重启服务或重新加载模型。

**有益效果：**
- **场景适应性强**：针对密集细胞、稀疏细胞、模糊图像等不同场景，用户可调整参数组合以获得最佳检测效果。
- **操作简便**：参数修改无需重启服务或重新加载模型，下次点击计数按钮时新参数自动生效。
- **灵活度高**：用户可根据实际需求在速度和精度之间权衡选择（快速模式vs精细模式）。

### 3.6 综合有益效果总结
