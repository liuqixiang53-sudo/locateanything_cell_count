## 第一章 概述

### 1.1 软件名称及版本

- **软件名称**：菌落与细胞计数分析软件
- **版本号**：V1.0

### 1.2 开发背景

在微生物学和细胞生物学实验中，菌落计数和细胞计数是基础且关键的环节。传统人工计数方式效率低、易疲劳、主观误差大，尤其在处理大批量样本或高密度菌落/细胞时，计数结果的准确性和一致性难以保证。

本软件基于 NVIDIA LocateAnything-3B 视觉语言模型，结合 CLAHE 图像增强、分水岭分割、非极大值抑制（NMS）等传统图像处理算法，实现了菌落与细胞的自动检测计数，并提供可视化、可交互的人工修正手段，兼顾自动化效率与结果准确性。

### 1.3 适用范围

本软件适用于微生物学、细胞生物学实验室及相关科研、教学场景中，对培养皿菌落图像和显微镜细胞图像进行计数分析，输出可用于记录、统计和后续分析的结构化数据。

### 1.4 主要功能简介

本软件通过浏览器访问，提供两大核心功能模块：

**菌落计数模块**：采用自适应两阶段检测策略。先在原始图像上进行粗定位，再根据候选菌落数量自动判断稀疏、中等、密集三种密度情形，分别采用直接检测、局部增强重新检测、分水岭分割等不同处理方式，得到最终菌落计数结果。

**细胞计数模块**：基于 LocateAnything-3B 模型进行细胞检测，支持框选感兴趣区域（ROI）以减少背景干扰，并支持在速度与精度之间选择不同的推理模式。

两个模块均支持：
- 手动添加/删除标记点，对自动检测结果进行修正；
- 多步撤销与一键重置；
- 计数结果一键导出为 CSV 文件，便于存档和后续分析。

## 第三章 安装、启动与卸载

### 3.1 安装前准备

**第一步：创建虚拟环境**

```bash
cd locateanthing_colony_count
python -m venv locateanthing
source locateanthing/bin/activate
```

**第二步：安装依赖**

```bash
pip install -r colony_cell_gui_fastapi/backend/requirements.txt
pip install transformers accelerate
```

**第三步：准备模型文件**

确保模型目录位于项目根目录下，目录结构如下：

```
locateanthing_colony_count/
├── LocateAnything-3B/
│   ├── config.json
│   ├── model-00001-of-00002.safetensors
│   ├── model-00002-of-00002.safetensors
│   ├── tokenizer_config.json
│   ├── ...
├── colony_cell_gui_fastapi/
└── ...
```

### 3.2 服务启动

**方式一：使用启动脚本（推荐）**

```bash
cd colony_cell_gui_fastapi
chmod +x run_fastapi.sh
./run_fastapi.sh
```

**方式二：手动启动**

```bash
cd colony_cell_gui_fastapi/backend
source ../../locateanthing/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000
```

启动成功后，在浏览器访问 http://localhost:8000 即可使用。首次启动时后台会自动加载模型文件，耗时约 1-2 分钟，加载完成前访问计数功能会等待模型加载结束。

### 3.3 服务停止与卸载

**停止服务**：

在运行 `uvicorn` 的终端窗口按 `Ctrl + C` 即可停止服务；若以后台方式启动，可通过以下命令查找并结束进程：

```bash
# 查找监听 8000 端口的进程
lsof -i:8000
# 结束进程（PID 替换为实际进程号）
kill -9 <PID>
```

**卸载软件**：

1. 停止正在运行的服务（见上）。
2. 退出并删除 Python 虚拟环境：

```bash
deactivate
rm -rf locateanthing
```

3. 如无需保留历史数据，可删除运行期间生成的缓存与结果目录：

```bash
rm -rf colony_cell_gui_fastapi/uploads
rm -rf colony_cell_gui_fastapi/results
```

4. 如需彻底移除本软件，删除项目根目录（含模型文件目录 `LocateAnything-3B/`）即可。

## 第四章 功能操作说明

### 4.1 主界面总体布局

软件主界面由以下部分组成：

1. **标题栏**：顶部区域，显示软件名称、版本号，以及"红点=自动检测 | 绿点=手动添加 | 点击已有点可删除"的操作提示；

3. **左侧面板**：包含图片上传区、操作按钮、参数调节面板、信息显示区；
4. **右侧面板**：包含统计区、画布工具栏、画布显示区。

【图4-1：软件主界面 - 标签页切换与整体布局】

### 4.2 菌落计数功能

#### 4.2.1 菌落计数标签页布局

菌落计数标签页左侧面板从上到下依次为：上传图片区域、图片信息、操作按钮（开始计数/撤销/重置/导出结果）、参数调节面板（可折叠）、信息显示区；右侧面板从上到下依次为：统计区、工具栏（缩放/平移/适应）、画布区。

【图4-2：菌落计数界面 - 左侧面板整体布局】

#### 4.2.2 图片上传

**操作步骤**：

1. 点击顶部标签栏的「菌落计数」标签，切换到菌落计数界面；
2. 点击左侧面板的上传区域，或在上传区域内拖拽图片文件；
3. 支持常见图片格式（JPG、PNG 等）；
4. 上传成功后，图片显示在右侧画布区域，上传区域显示文件名，图片信息区显示分辨率（宽 x 高，单位像素）。

上传新图片时，系统会自动清空当前的标记点、操作历史和画布缩放/平移状态，恢复为初始视图。

【图4-3：菌落计数 - 图片上传成功后的界面】

#### 4.2.3 参数调节

点击左侧面板的「参数调节面板」展开参数设置区域。所有参数均直接影响自动计数算法，用户可根据实际样本情况调节：

| 参数名称 | 默认值 | 可调范围 | 功能说明 |
|----------|--------|----------|----------|
| 稀疏阈值 | 50 | 5 - 300 | 候选框数量低于此值时，判定为稀疏密度，直接使用模型检测结果 |
| 密集阈值 | 150 | 20 - 500 | 候选框数量高于此值时，判定为密集密度，启用分水岭分割 |
| NMS IoU 阈值 | 0.3 | 0.1 - 0.9 | 非极大值抑制的重叠判定阈值，值越小过滤越严格 |
| 去重距离 (px) | 3.0 | 1 - 20 | 中心点去重的像素距离阈值，小于该距离的重复点将被合并 |
| CLAHE 对比度限制 | 2.0 | 0.5 - 10 | 对比度增强的上限，值越大增强越强，但可能放大噪声 |
| CLAHE 网格大小 | 8 | 4 - 16 | CLAHE 分块处理的网格数量，值越大局部增强越精细 |
| 分水岭面积因子 | 2.0 | 0.5 - 5 | 触发分水岭分割的面积阈值因子，值越小越多框触发分割 |
| 分水岭距离比 | 0.3 | 0.1 - 0.8 | 距离变换阈值比例，影响种子点筛选的严格程度 |
| 分水岭最小面积比 | 0.0005 | 0.0001 - 0.005 | 分割后子区域的最小面积比例，过小的区域将被过滤 |

参数调节区每个滑块右侧均实时显示当前数值，拖动滑块即可即时预览设定值，设置完成后点击「开始计数」生效。

【图4-4：菌落计数界面 - 参数调节面板展开状态】

> 提示：一般情况下使用默认参数即可获得较好效果。若菌落密度较高导致漏检，可适当降低密集阈值；若菌落粘连严重导致欠分割，可调整分水岭相关参数。

#### 4.2.4 自动计数

**操作步骤**：

1. 点击「开始计数」按钮，触发自动检测（该按钮在未上传图片时保持禁用状态）；
2. 系统显示加载动画，提示"正在进行菌落计数..."；
3. 后台依次执行：图像预处理（CLAHE 增强）→ 模型推理获取候选框 → 密度分析与分层处理 → NMS 过滤与去重 → 绘制检测结果（红点标注）；
4. 计数完成后，画布显示标注结果，左侧统计区显示当前数量，信息显示区展示"阶段 | 原始检测数 | 最终计数"等详细信息。

【图4-5：菌落计数界面 - 计数完成后的画布效果（红点=自动，绿点=手动）】

#### 4.2.5 手动添加/删除标记点

- **添加点**：在画布空白处点击，添加一个绿色手动标记点；
- **删除点**：点击已有的标记点（红色或绿色），删除该点。系统以点击位置与标记点中心的距离判定是否命中，命中范围会随画布缩放比例自适应调整，因此放大画面后可以更精确地点选密集区域中的某一个点；
- 手动添加的点显示为绿色，自动检测的点显示为红色，便于区分；
- 每一次增加或删除标记点的操作都会被记录到操作历史中，可通过「撤销」逐步回退。

#### 4.2.6 撤销与重置

- **撤销**：点击「撤销」按钮，回退到上一次操作状态（支持多步撤销，直至恢复到初始检测结果或空白状态）；
- **重置**：点击「重置」按钮，清除所有标记点和操作历史，恢复原始图像及初始缩放视图。

#### 4.2.7 导出 CSV 结果

点击「导出结果」按钮，系统将当前所有标记点（包括自动检测和手动添加）导出为 CSV 文件，包含以下字段：

| 字段 | 说明 |
|------|------|
| 序号 | 点的编号，从 1 开始 |
| X | 中心点 X 坐标（像素） |
| Y | 中心点 Y 坐标（像素） |
| 类型 | "自动" 或 "手动" |

文件末尾包含总计数量，文件编码为 UTF-8 BOM，可直接用 Excel 打开，不会出现中文乱码。文件名格式：`菌落_计数结果_YYYY-MM-DD-HH-MM-SS.csv`。

### 4.3 细胞计数功能

#### 4.3.1 细胞计数标签页布局

细胞计数标签页与菌落计数标签页布局类似，主要区别为：操作按钮为「裁剪并计数」（替代"开始计数"）；参数调节面板包含 3 个参数（NMS IoU、温度、推理模式）；工具栏额外包含模式切换按钮（标点模式/框选模式）；信息显示区显示裁剪区域信息和计数结果。

【图4-6：细胞计数界面 - 左侧面板整体布局】

#### 4.3.2 图片上传

**操作步骤**：

1. 点击顶部标签栏的「细胞计数」标签，切换到细胞计数界面；
2. 点击左侧面板的上传区域，或在上传区域内拖拽图片文件；
3. 上传成功后，图片显示在右侧画布区域，图片信息区显示分辨率信息。

【图4-7：细胞计数 - 图片上传成功后的界面】

#### 4.3.3 框选区域

细胞计数支持两种交互模式，通过工具栏的模式切换按钮选择：

- **标点模式**：点击画布添加/删除标记点（默认模式）；
- **框选模式**：拖拽鼠标绘制矩形框，选择感兴趣区域（ROI）。

**框选操作步骤**：

1. 点击工具栏的「框选模式」按钮，此时按钮高亮显示为已激活状态；
2. 在画布上按住鼠标左键并拖拽，绘制矩形框；
3. 松开鼠标后，框选区域以虚线矩形显示（若拖拽范围过小，系统会自动判定为无效框选并清除，避免误触）；
4. 点击「裁剪并计数」后，系统仅对框选区域进行推理检测；若未进行框选，则默认对整张图片进行检测。

【图4-8：细胞计数界面 - 框选模式下的画布效果（虚线矩形框选区域）】

> 提示：框选功能适用于细胞分布不均匀或只需计数特定区域的情况，可减少背景干扰并提高检测精度。切换回「标点模式」后，之前绘制的框选区域仍会保留，直至重新框选或点击「重置」。

#### 4.3.4 参数调节

点击左侧面板的「参数调节面板」展开参数设置区域：

| 参数名称 | 默认值 | 可调范围 | 功能说明 |
|----------|--------|----------|----------|
| NMS IoU 阈值 | 0.3 | 0.1 - 0.9 | 非极大值抑制的重叠判定阈值，值越小过滤越严格 |
| 温度 | 0.1 | 0.0 - 1.0 | 模型生成的采样温度，数值越高结果多样性越强，数值越低结果越稳定保守 |
| 推理模式 | 混合模式 | 混合/快速/精细 | 选择模型推理策略，影响速度与精度的平衡 |

推理模式说明：
- **混合模式（Hybrid）**：结合多 Token 并行解码和标准自回归解码，平衡速度与精度（推荐）；
- **快速模式（MTP）**：多 Token 并行解码，速度最快；
- **精细模式（NTP）**：标准自回归解码，精度最高。

#### 4.3.5 自动计数

**操作步骤**：

1. （可选）在框选模式下选择感兴趣区域；
2. 点击「裁剪并计数」按钮（该按钮在未上传图片时保持禁用状态）；
3. 系统显示加载动画，提示"正在进行细胞计数..."；
4. 后台依次执行：裁剪选中区域（如有）→ 模型推理检测细胞 → 解析边界框坐标 → NMS 过滤重叠框 → 绘制检测结果（红点标注）；
5. 计数完成后，画布显示标注结果，左侧统计区显示当前数量，信息显示区展示裁剪区域坐标、原始检测数与最终计数。

【图4-9：细胞计数界面 - 计数完成后的画布效果】

#### 4.3.6 手动添加/删除标记点

与菌落计数相同：
- **添加点**：在标点模式下，点击画布空白处添加绿色手动标记点；
- **删除点**：点击已有的标记点，删除该点。

#### 4.3.7 撤销与重置

与菌落计数相同：
- **撤销**：回退到上一次操作状态；
- **重置**：清除所有标记点和框选区域，恢复原始图像。

#### 4.3.8 导出 CSV 结果

与菌落计数相同，字段和编码格式一致，文件名格式：`细胞_计数结果_YYYY-MM-DD-HH-MM-SS.csv`。

### 4.4 画布通用交互操作

画布区域支持以下交互操作，两个功能模块通用：

| 操作 | 方式 | 说明 |

## 第五章 操作演示案例

本章以完整的操作流程为例，演示菌落计数和细胞计数从上传图片到导出结果的全过程，帮助用户快速掌握软件的典型使用方法。

### 5.1 菌落计数完整案例演示

**场景**：某实验室对一张培养皿平板照片进行菌落计数，菌落分布中等密度，边缘存在少量粘连。

1. **上传图片**：在「菌落计数」标签页点击上传区域，选择本地培养皿照片（如 `plate_01.jpg`），上传成功后画布显示原图，图片信息区显示分辨率，例如 `1600 x 1200 px`；
2. **确认/调整参数**：展开参数调节面板，本例中样本密度中等，保持默认参数（稀疏阈值 50、密集阈值 150、NMS IoU 0.3 等）不变；
3. **执行自动计数**：点击「开始计数」，等待加载提示消失后，画布上出现红色标记点覆盖识别到的菌落，信息显示区展示如"阶段: medium | 原始检测: 96 | 最终计数: 89"的提示，说明系统判定为中等密度，经二次增强检测与去重后最终识别 89 个菌落；
4. **人工核查与修正**：将画布放大（Ctrl+滚轮或点击"+"按钮），逐一核对边缘粘连区域，发现 2 处漏检的菌落，直接在对应空白位置点击，添加 2 个绿色手动标记点，当前数量变为 91；同时发现 1 处误检的杂质被识别为菌落，点击该红色标记点将其删除，当前数量变为 90；
5. **导出结果**：确认统计区显示当前数量为 90 后，点击「导出结果」，浏览器下载文件 `菌落_计数结果_2026-07-11-14-30-00.csv`，文件包含 90 条记录（88 条"自动"、2 条"手动"）及坐标信息，末尾附总计数量，可直接用 Excel 打开归档。

### 5.2 细胞计数完整案例演示

**场景**：某实验室对一张显微镜细胞图像进行局部区域计数，仅需统计视野中央的细胞聚集区。

1. **上传图片**：在「细胞计数」标签页上传显微镜图像（如 `cell_field_03.png`），画布显示原图；
2. **框选感兴趣区域**：点击工具栏「框选模式」按钮，在画布上拖拽绘制矩形框，圈定视野中央的细胞聚集区域，松开鼠标后该区域以虚线矩形高亮显示；
3. **确认推理参数**：展开参数调节面板，根据需要将「推理模式」设置为"精细模式（NTP）"以获得更高精度（默认混合模式已能满足大部分场景）；
4. **执行裁剪并计数**：点击「裁剪并计数」，等待加载提示"正在进行细胞计数..."消失后，画布仅在框选区域内显示红色标记点，信息显示区展示如"裁剪区域: (320,180)-(860,540) | 原始检测: 142 | 最终计数: 131"的提示；
5. **人工核查与修正**：切换回「标点模式」，对紧密贴合、疑似漏检的细胞手动补点，对明显重复标记的点予以删除，确认最终数量；
6. **导出结果**：点击「导出结果」，下载文件 `细胞_计数结果_2026-07-11-15-05-00.csv`，供后续统计分析使用。

## 第七章 常见问题及解决方法

**Q1：首次启动服务后，为什么迟迟没有响应？**

A：首次启动服务时，系统需要将模型文件加载至 GPU 显存，该过程耗时约 1-2 分钟。建议在启动后等待终端输出模型加载完成的提示后，再进行上传和计数操作。

**Q2：计数时提示显存不足或计数失败，应该怎么办？**

A：本软件运行时需要约 6-8GB GPU 显存。如果显存不足，可尝试：关闭其他占用 GPU 显存的程序；处理高分辨率图像时适当降低图像尺寸或分批处理；确认所用 GPU 显存不低于 8GB。

**Q3：菌落计数/细胞计数一般需要多长时间？**

A：菌落计数根据图像大小和菌落密度，耗时约 5-30 秒，密集区域通常比稀疏区域耗时更长；细胞计数根据图像大小和推理模式，耗时约 10-60 秒，其中"精细模式"耗时相对最长。

**Q4：导出的 CSV 文件用 Excel 打开出现乱码，怎么解决？**

A：导出的 CSV 文件使用 UTF-8 BOM 编码，可直接用 Microsoft Excel 打开，不会出现中文乱码。如果使用其他文本编辑器打开，请注意手动选择 UTF-8 编码。

**Q5：本软件对浏览器有什么要求？**

A：本软件基于 HTML5 Canvas、Fetch API 等现代 Web 技术开发，推荐使用 Google Chrome 90+、Mozilla Firefox 88+、Microsoft Edge 90+ 或 Safari 14+ 浏览器访问。

**Q6：如何在其他电脑上通过网络访问本软件？**

A：服务默认监听 `0.0.0.0:8000`，支持远程访问。推荐使用 SSH 端口转发方式：

```bash
ssh -L 8000:localhost:8000 user@remote-server
```

转发成功后，在本地浏览器访问 http://localhost:8000 即可。

**Q7：菌落粘连严重，分割效果不理想，如何调整？**

A：可在参数调节面板中适当降低「分水岭面积因子」，使更多候选框触发分割；也可调整「分水岭距离比」和「分水岭最小面积比」，改变种子点筛选的严格程度和子区域过滤阈值。

**Q8：自动检测结果有漏检或误检，如何修正？**

A：可在画布上直接手动修正：点击空白处添加遗漏的标记点（显示为绿色），点击已有的错误标记点将其删除；如误操作，可点击「撤销」按钮逐步回退。

**Q9：为什么「开始计数」「撤销」「导出结果」等按钮呈灰色无法点击？**

A：这些按钮设计为按状态自动禁用：未上传图片时「开始计数/裁剪并计数」不可用；没有操作历史时「撤销」不可用；没有任何标记点时「导出结果」不可用。按提示完成前置操作后按钮会自动恢复可用状态。

**Q10：上传图片失败或没有反应，可能是什么原因？**

A：请检查图片格式是否为常见格式（JPG、PNG 等），文件是否损坏；如使用拖拽上传，请确认将文件直接拖拽到虚线框区域内再松开鼠标。

**Q11：细胞计数的框选区域怎么重新绘制？**

A：直接在框选模式下重新拖拽绘制新的矩形框，新框选区域会替换旧的框选区域；也可点击「重置」清除框选区域及全部标记点，从原始图像重新开始。

**Q12：能否同时处理多张图片？**

A：当前 Web 界面按单张图片进行交互式计数与修正。如需批量处理，可使用项目提供的命令行脚本（`colony_count_adaptive.py`、`count_simple.py`）指定图片目录进行批量检测，具体用法可参考脚本内的命令行参数说明。

**Q13：调整参数后为什么计数结果没有变化？**

A：参数调节面板中的数值仅在下一次点击「开始计数」/「裁剪并计数」时生效，调整参数后需要重新点击对应按钮触发计数，才能应用新的参数设置。

| 参数名 | 类型 | 默认值 | 必填 | 说明 |

| clahe_clip_limit | float | 2.0 | 否 | CLAHE 对比度限制 |
| tile_grid_size | int | 8 | 否 | CLAHE 网格大小 |
| watershed_area_factor | float | 2.0 | 否 | 分水岭面积因子 |
| watershed_dist_ratio | float | 0.3 | 否 | 分水岭距离比 |
| watershed_min_area_ratio | float | 0.0005 | 否 | 分水岭最小面积比 |

**响应**（JSON）：

```json
{
  "success": true,
  "count": 125,
  "raw_count": 142,

    {"x": 123.5, "y": 456.7, "source": "auto"}
  ],
  "image_base64": "..."
}
```

## 附录C 术语表

| 术语 | 说明 |
|------|------|
| 菌落 | 微生物在固体培养基上生长繁殖形成的肉眼可见的群体 |
| ROI（感兴趣区域） | 用户在图像中框选的、需要重点计数分析的局部区域 |
| CLAHE | 对比度受限自适应直方图均衡化，一种图像局部对比度增强算法 |
| NMS（非极大值抑制） | 用于去除重叠冗余检测框的后处理算法 |
| 分水岭分割 | 一种用于分割相互粘连目标的图像处理算法 |
| 推理模式 | 指模型生成检测结果时采用的解码策略，分为快速（MTP）、精细（NTP）、混合（Hybrid）三种 |
| 自动检测点 | 由模型算法自动识别得出的标记点，画布中显示为红色 |
| 手动标记点 | 由用户在画布上手动添加的标记点，画布中显示为绿色 |
| 原始检测数 | 算法初步检测（去重/分割前）得到的候选目标数量 |
| 最终计数 | 经过完整算法流程（含去重、分割、用户手动修正）后的最终数量 |
